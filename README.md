# dotfiles

Uses [chezmoi](https://www.chezmoi.io/) for management and [Starship](https://starship.rs/) for the terminal theme.

## Install

1. [Install Starship](https://starship.rs/guide/#%F0%9F%9A%80-installation)
2. [Install chezmoi](https://www.chezmoi.io/install/)
3. Run ```chezmoi init --apply brugr```
